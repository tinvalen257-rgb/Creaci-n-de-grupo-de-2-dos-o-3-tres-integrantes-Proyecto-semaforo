# Creaci-n-de-grupo-de-2-dos-o-3-tres-integrantes-Proyecto-semaforo
https://wokwi.com/projects/477419813686273025
REQUERIMIENTOS FUNCIONALES
RF1  Encendido de luz roja: El sistema debe encender la luz roja para indicar que los vehículos deben detenerse
RF2  Encendido de luz verde: El sistema debe encender la luz verde para indicar que los vehículos pueden avanzar
RF3  Encendido de luz amarilla: El sistema debe encender la luz amarilla para advertir que se aproxima un cambio de señal
RF4  Cambio automático de luces: El sistema debe cambiar automáticamente entre las luces roja, verde y amarilla siguiendo una secuencia programada
RF5  Control de tiempos: El sistema debe mantener cada luz encendida durante un tiempo determinado antes de pasar a la siguiente señal
REQUERIMIENTOS NO FUNCIONALES
Los requerimientos no funcionales describen las condiciones de calidad y funcionamiento que debe cumplir el sistema
RNF1  Seguridad eléctrica: El circuito debe utilizar resistencias adecuadas para proteger los LED y evitar daños en los componentes
RNF2  Confiabilidad: El semáforo debe ejecutar la secuencia programada de manera continua y sin interrupciones inesperadas
RNF3  Claridad visual: Las luces deben distinguirse claramente para identificar cada señal
RNF4  Bajo consumo: El sistema debe utilizar componentes de bajo consumo eléctrico
RNF5  Mantenibilidad: El código debe estar organizado y comentado para facilitar futuras modificaciones y reparaciones
HISTORIAS DE USUARIO
Las historias de usuario describen las necesidades del usuario y el beneficio que espera obtener
HU1  Señal de detención: Como conductor, quiero ver la luz roja encendida para saber cuándo debo detenerme
HU2  Señal de avance: Como conductor, quiero ver la luz verde encendida para saber cuándo puedo avanzar
HU3  Señal de precaución: Como conductor, quiero ver la luz amarilla encendida para anticiparme a un cambio de señal
HU4  Funcionamiento automático: Como usuario, quiero que el semáforo cambie las luces automáticamente para no tener que controlarlo manualmente
HU5  Duración de las señales: Como usuario, quiero que cada luz permanezca encendida durante un tiempo establecido para que la secuencia sea ordenada y predecible
